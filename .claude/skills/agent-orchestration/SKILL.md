新機能を実装するときは以下の順でエージェントを呼び出してください。

## 実装フロー

```
1. finlearn.spec-writer     仕様書作成
        ↓
2. finlearn.tdd-implementer テストコード作成 → 実装
        ↓
3. (レビューエージェント)   コードレビュー  ※未作成
```

## 各エージェントの役割

| エージェント | 役割 | 成果物 |
|---|---|---|
| `finlearn.spec-writer` | コードとヒアリングをもとに機能仕様書を作成 | `docs/specs/<機能名>.md` |
| `finlearn.tdd-implementer` | 仕様書を読んでxUnitテストを書き、テストが通る実装を行う | テストコード + 実装コード |
| レビューエージェント（未作成） | 実装済みコードをレビュー | レビューコメント |
