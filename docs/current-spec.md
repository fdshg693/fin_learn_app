# 現在の仕様まとめ

更新日: 2026-03-08

## このドキュメントについて
この資料は、現時点でユーザーが体験できる仕様をまとめたものです。
技術的な構成や実装方法は省き、機能と挙動のみを記載しています。

## アプリの目的
株の売買を疑似体験しながら、ポートフォリオの変化（現金・保有・評価額・損益）を学ぶこと。

## 現在できること

### 1. 銘柄情報の確認
- 銘柄一覧を表示できる
- 銘柄の詳細情報を表示できる

### 2. ポートフォリオの確認
- 投資家のポートフォリオを表示できる
- 現金、保有銘柄、評価額、損益を確認できる

### 3. アクション実行
- 今すぐ買う / 指値で買う
- 今すぐ売る / 指値で売る
- 待つ（Wait）

API 上は買いが `POST /api/actions/buy`、売りが `POST /api/actions/sell` に統合されており、`limitPrice` の有無で成行 / 指値が切り替わる。

### 4. ターン制
- 1回アクションを実行すると1ターン進む
- 画面に現在ターンが表示される
- 古いターン情報で実行すると競合エラーになる

### 5. 市場の自動更新
- ターンが進むたびに株価が自動で変動する
- ターンごとにコンピューターの買い注文・売り注文が生成される
- システム注文どうしでクロスした場合は、そのターン内に自動で約定する

### 6. 約定の挙動
- 買い/売りともに、条件に合う注文とマッチした分だけ約定する
- 全量約定しない場合は、部分約定として結果が返る
- 条件に合う注文がなければ約定しない

### 7. 注文票と約定履歴の表示
- 注文票（買い）を表示できる
- 注文票（売り）を表示できる
- 約定履歴を表示できる
- アクション実行後に表示内容が更新される

## 現在の前提・制約
- 対象の投資家はデモ用の1名
- 注文はシミュレーション用の簡易ルールで処理される
- 指値注文は「条件に合う分をその場で約定する」動きで、未約定分を後で待つ注文として残す仕様にはなっていない

## これから実装する内容（予定）

### 優先度: 高
1. 指値注文の未約定分を注文として残す
- いわゆる「板に置く」指値注文に対応する

2. 注文の取り消し機能
- 既に出している注文を取り消せるようにする

3. 競合エラー時の再同期体験の改善
- エラー後に状態を取り直し、再実行しやすくする

### 優先度: 中
1. 注文票の使い勝手向上
- 並び替え
- 絞り込み（銘柄別など）
- 表示件数の調整

2. 約定結果の見やすさ向上
- どの注文がどれだけ約定したかをより分かりやすく表示

3. ターン進行の演出・説明
- 価格変動理由やターンイベントの見える化

### 優先度: 低
1. 複数投資家の扱い
- 複数ユーザーや複数ポートフォリオを扱えるようにする

2. 学習向けガイドの強化
- 初学者向けに売買の流れや結果の読み方をチュートリアル化

## 受け入れイメージ（次フェーズ）
- 指値注文を出した後、条件に合うまで注文票に残る
- 後続ターンで条件成立したら自動的に約定する
- 不要になった注文はユーザーが取り消せる
- エラー時にも次の操作にスムーズに戻れる
