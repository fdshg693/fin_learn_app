# アプリケーション機能要件

## 最小構成（実装済み）

- 銘柄一覧・詳細表示
- ポートフォリオ表示（保有銘柄・現金・評価額・損益）
- アクション実行（BuyNow / SellNow / BuyLimit / SellLimit / Wait）
- ターン制シミュレーション
- コンピュータ注文・オーダーマッチング

## 今後の拡張候補

### 優先度: 高
- 入力バリデーション（FluentValidation + Zod）
- テストコード（xUnit）

### 優先度: 中
- グラフ描画（Recharts 等）でポートフォリオを可視化
- TanStack Table を使った銘柄・取引履歴の表示

### 優先度: 低
- 外部 API 連携（Yahoo Finance 等のリアル株価取得）
- データエクスポート（CSV / JSON）
- 価格アラート通知
- ユーザー認証・複数ポートフォリオ管理
- レポート生成・PDF エクスポート
